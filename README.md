# AOUSD Build Interest Group – Initiatives

This repository is used by the **[Alliance for OpenUSD (AOUSD)](https://aousd.org/) [Build Interest Group](https://aousd.org/community/interest-groups/)** to coordinate efforts among its members: prioritizing goals, tracking initiatives, and linking to relevant pull requests and issues.

**This repository is *read-only* for the public.** Content is maintained by Build Interest Group members for internal coordination and transparency.

## Where to contribute

**If you wish to contribute code, bug fixes, or features to OpenUSD:**

- please use the main OpenUSD repository, at [PixarAnimationStudios/OpenUSD](https://github.com/PixarAnimationStudios/OpenUSD).

**If you wish to participate in the [Alliance for OpenUSD (AOUSD)](https://aousd.org/) [Build Interest Group](https://aousd.org/community/interest-groups/) directly, and coordinate, propose, or prioritize initiatives in *this* repository:**

- you must work at a company which has joined the [Alliance for OpenUSD (AOUSD)](https://aousd.org/), at least as a Contributing Member, and ask to join the [Build Interest Group](https://aousd.org/community/interest-groups/). (There is NO FEE for companies to join at the Contributor level, though!)

## Terms

- **[Alliance for OpenUSD (AOUSD)](https://aousd.org/)** is a governance and member organization that aims to foster the standardization, development, evolution, and growth of OpenUSD.
- **[AOUSD Build Interest Group](https://aousd.org/community/interest-groups/)** is an interest group, hosted by [AOUSD](https://aousd.org/), which focuses on improving the developer experience with OpenUSD by reducing friction in build systems and tooling. 
- **[OpenUSD](https://github.com/PixarAnimationStudios/OpenUSD)** is the open-source USD codebase and specification, hosted in the Pixar repositories.
